## 构建边界

RTL 展开、顶层综合、布局布线和板级测试是不同验证层级。模块仿真只覆盖除法器和同步延迟，没有验证整个 ISP 图像算法、DDR 模型、I2C 或 UDP 协议。当前没有整机 golden image 对比结果，也没有可承诺的帧率、资源占用、功耗或时序裕量。

## 查漏结果

| 位置 | 发现 | 影响 / 后续验证 |
| --- | --- | --- |
| 原 README / 原根目录顶层 | 文档描述旧副本，实际 XPR 使用另一份顶层 | 已将实际活动版本迁到 `src/`、`rtl/`，旧版归档至 `legacy/` |
| XPR / 顶层头文件 | 工程依赖导入目录及运行目录相对路径 | 已统一工程源路径和显示头文件搜索目录 |
| 部分 BRAM/FIFO IP | 快照缺少生成输出 | 构建脚本从 XCI 重生成，并构建所需 IP |
| `src/axi/axi4_ctrl.v` | `C_BUF_SIZE=60`，帧索引拼接结果输出到 32 位地址 | 高位截断可能使四帧缓冲区别名，需确认 DDR 地址布局 |
| 顶层显示读链路 | 640×640 帧数据配合 1280×720 显示请求 | 需检查读请求总量、FIFO underflow、窗口内容与帧同步 |
| `src/eth/Pixeldata2eth.v` | 420 像素窗口与 802 字节 UDP payload 不一致 | 需统一像素数量、行标记、包长和 FIFO 字节序 |
| `src/eth/UDP_TOP.v` | 发送触发跨时钟域直连；打包 FIFO 未用 full/empty 保护 | 需补跨域和吞吐测试后决定协议调整 |
| `src/io/lag_module.v` | 默认 `LAG1=1` 的 part-select 下界为负 | 当前顶层明确覆盖为 6；复用时需验证参数边界 |
| `legacy/` | 旧顶层缺失 `pixel_filter_to_fifo`，Sobel 实验缺失处理模块 | 已与活动源码区分，不用于当前构建 |

这些功能风险保留原始行为，并在相关说明中标出。需要板卡配置和整机验证才能确认修复方案，不能通过重新排版或一次模块仿真消除。
