# 上板与参数说明

## 时钟和复位

| 时钟域 | 用途 | 入口 |
| --- | --- | --- |
| 25 MHz | I2C 配置、系统参考 | `clk25m_i` |
| 27 MHz | 相机 XCLK、显示 PLL 参考 | `clk27m_i` |
| DVP PCLK | 采集、Bayer 解码、插值输入 | `cmos_pclk_i` |
| 200 MHz | 插值输出、DDR 写 FIFO 输入、IDELAY 参考 | `PLL_25_200` |
| MIG UI | DDR AXI 总线 | `DDR3_0.ui_clk` |
| 74.25 MHz | 720p 光栅、滤波、锐化、像素打包 | 显示 PLL |
| 371.25 MHz | TMDS 串行化 | 显示 PLL |
| PHY 时钟 | GMII/RGMII 发送与接收 | `eth_refclk_i` / `eth_rxc_i` |

相机采集通过 I2C 完成信号和 MIG 校准完成信号启动。I2C 使用 PLL 锁定作为复位释放条件，图像流水线使用显示域复位，以太网使用外部复位。修改复位行为前检查跨域释放时序。

`lag_module` 的 6/47/47 延迟是当前顶层配置。改变处理级后，重新测量 RGB 与 VS/HS/DE 的关系。

## DDR 和显示

顶层向 DDR 写入的每个像素为 32 位 `{B,R,G,B}`；显示端取低 24 位，即 `{R,G,B}`。高字节重复蓝色，不能当作独立 alpha 通道使用。

`C_RD_END_ADDR = 640*640*4` 是读取字节上界；`C_BUF_SIZE` 是每帧地址偏移的**位数**。当前继承值为 60，而 AXI 地址输出只有 32 位，帧索引会在截断时丢失。需结合实际 DDR 容量确认缓冲区分配，再进行读写交叠测试。

显示为 1280×720，插值结果为 640×640；`lcd_request` 驱动 DDR 读取。当前没有经验证的整帧重采样/重复读取策略，需检查每帧读取量、FIFO underflow 和窗口数据对应关系。

`FrameBoundCrop` 保留原光栅与 DE，只把窗口外像素置为 `24'h111111`；其 `rst_i` 当前未参与逻辑。

## 以太网

活动路径为 `UDP_TOP` → `PixelData2Eth` / `UDP_SEND_READ_top` → `UDP_Send`，使用 `rgb2eth` 完成 16 位到 8 位的异步 FIFO 转换。

| 项目 | 当前配置 |
| --- | --- |
| 源 IP / UDP 端口 | `192.168.1.2:8080` |
| 源 MAC | `00:0a:35:01:fe:c0` |
| 目标 IP / UDP 端口 | `192.168.1.102:8080` |
| 目标 MAC | `04:d4:c4:72:85:6f`，按接收端网卡修改 |
| 请求 payload 长度 | 802 字节 |
| 像素格式 | RGB565 |
| 帧标记字 | `16'hAAAA`、`16'hBBBB` |

像素窗口列范围为 `[476,896)`，即 420 个像素、840 字节，尚未与 802 字节包长统一。行号/帧标记另有使能窗口，不能假设每个 UDP 包严格对应一行图像。FIFO 字节顺序需要仿真或抓包确认。

`o_eth_send_Go` 从像素域直接送往发送域，FIFO 的 `full`/`empty` 没有用于阻止越界操作。需验证跨域触发、FIFO 清空时序、包长和丢包处理。活动链路没有动态 ARP 解析；`legacy/rtl/UDP/` 的备用协议栈不属于当前顶层。

## 调试顺序

1. 对照板卡原理图核对 XDC，尤其是 I/O 电平、DDR 引脚、PHY 时钟和延迟。
2. 检查 PLL 锁定和 MIG 校准，再确认 I2C ACK、相机 XCLK 和 400×400 行帧计数。
3. 用固定图案验证 DDR 帧地址、FIFO 水位、RGB 顺序和显示窗口。
4. 分别检查 Bayer、插值、滤波、锐化的图像与同步对齐。
5. 配置目标 MAC/IP，抓包核对 UDP 校验、长度、标记、字节序和行序。
6. 检查实现后的 setup/hold、CDC 和 DRC，再进行连续帧运行测试。

仓库未提供板卡原理图、相机数据手册、上位机重组软件或已验证 bitstream。
